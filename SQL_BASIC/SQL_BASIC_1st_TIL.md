## 🧩 문제 1

포켓몬 게임이나 이커머스 산업과 같이 다양한 산업에서는 각기 다른 데이터가 존재합니다. 다음 중 하나의 산업을 선택하고, 해당 산업에서 수집하고 활용될 수 있는 데이터 항목, 즉 컬럼 5가지를 자유롭게 상상하여 나열해주세요.

예시 산업:
- 온라인 음식 배달
- 스마트 헬스 케어
- 중고 거래 앱
- 교육 플랫폼

풀이 과정:

```
- 선택한 산업: 온라인 음식 배달
- 떠올린 컬럼 5가지: 매장, 메뉴, 주문번호, 가격, 고객
- 해당 컬럼이 필요하다고 생각한 이유: 주문번호로 각 주문 건을 구분하고, 매장명과 메뉴명을 통해 어느 가게의 어떤 음식이 잘 팔리는지 파악할 수 있다. 주문금액은 매출과 직결되어 가격대별 주문 경향을 볼 수 있고, 고객ID가 있으면 재주문 여부나 고객별 이용 패턴까지 확인할 수 있다. 이 다섯 가지가 있으면 배달 앱에서 주문이 어떻게 일어나는지 전반적으로 살펴볼 수 있다고 생각했다.
```

## 🧩 문제 2

이번 강의를 통해 SQL이 왜 필요하다고 느끼는지, SQL을 통해 본인이 어떤 것을 해내고 싶은지를 자유롭게 작성해주세요.

풀이 과정:

```
- SQL이 필요하다고 느낀 이유: 실제 업무 상황에서 복잡한 데이터를 유의미하게 활용하기 위해 필요한 도구라는 생각이 들었다.
- SQL로 해보고 싶은 일: 실무에서 어떻게 활용되는지 실습을 통해 이해해보고 싶다. 
- 앞으로 SQL을 공부할 때 기대되는 점: 보다 더 데이터를 유용하게 활용할 수 있는 방법을 알게 될 것. ㅏㅌ아 기대된다.
```
