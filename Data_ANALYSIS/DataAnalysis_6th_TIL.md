## 02. 맷플롯립의 고급 기능 배우기

### 하나의 피겨에 여러 개의 선 그리기

#### 선 그래프 2개 그리기

- line 2개 만들어서 → `ax.plot()`
- `legend()` 메서드 : 범례 표시

#### 선 그래프 5개 그리기

- `for` 문 사용

```python
for pub in top30_pubs.index[:5]:
    line = ns_book9[ns_book9['출판사'] == pub]
    ax.plot(line['발행년도'], line['대출건수'], label=pub)
```

#### 스택 영역 그래프

- 하나의 선 그래프 위에 다른 선 그래프를 차례대로 쌓는 것
- `stackplot()` 메서드

1. `pivot_table()` 메서드로 각 '발행년도' 열의 값을 열로 바꾸기
2. '발행년도' 열을 리스트 형태로 바꾸기
3. `stackplot()` 메서드로 스택 영역 그래프 그리기

### 하나의 피겨에 여러 개의 막대 그래프 그리기

- `bar()` 메서드

#### 스택 막대 그래프

- 막대 그래프를 스택 영역 그래프처럼 위로 쌓는 그래프
- `bottom` 매개변수

### 원 그래프 그리기

- `pie()` 메서드

#### 단점

- 시각적으로 크기를 비교하기 어려움

#### 비율 표시하고 부채꼴 강조하기

- `autopct` 매개변수 : `%` 연산자에 적용할 포맷팅 문자열 전달
